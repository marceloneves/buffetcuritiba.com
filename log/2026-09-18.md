## Correção de erros e avisos de validação W3C (43 páginas)

### Corrigido
- Meta `http-equiv="Content-Type"` duplicada (charset já declarado via
  `<meta charset>`).
- `@charset "UTF-8";` embutido fora do início da folha de estilo, dentro
  do CSS concatenado (bootstrap/animate.css).
- Seletores inválidos de `@keyframes` no CSS do boxicons (`0{` em vez de
  `0%{`), 14 ocorrências.
- `font-size:3.0!important` sem unidade (`.bx-lg`) — alterado para `3em`.
- 4 declarações `@import` de fontes do Google Fonts que apareciam depois
  de outras regras no CSS — movidas para o início do bloco `<style>`.
- `font-family: unset,sans-serif` (valor inválido) — corrigido para
  `unset`.
- Dois blocos `<style>` que eram filhos de `<section>` (inválido) —
  movidos para o `<style>` principal do `<head>`.
- `<div>` não fechado na seção de FAQ da home (`index.html`), causando
  erro de elemento não fechado.
- Scripts de carregamento adiado (`type="SuperLazyLoad" src="...">`),
  inválidos por combinar um `type` não padrão com `src` — trocados para
  `type="text/plain" data-type="SuperLazyLoad" data-src="...">`, com o
  loader JS inline atualizado para ler `data-src`/`data-type` em vez de
  `src`/`type`.
- Breadcrumbs (schema.org) sem `itemscope` no `<ul>` e nos `<li>`,
  causando erros de `itemtype`/`itemprop` órfãos — `itemscope`
  adicionado em ambos.
- `blog/index.html`: section vazia sem heading convertida em `<div>`;
  heading `<h3>Solicite um orçamento</h3>` alterado para `<h2>` (pulava
  do `h1` direto pro `h3`).
- `contato/index.html`: títulos `<h4>` do bloco de contato (Endereço,
  Telefone, Whatsapp, E-mail) alterados para `<h3>` (pulavam do `h2`
  "Fale conosco" direto pro `h4`); seletor CSS correspondente
  (`.contact-side-box .info-box h4`) atualizado junto para preservar o
  estilo visual original.
